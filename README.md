# Smart Hosting — Version 4

Version 4 is a polished static website package for Smart Hosting (smartlyhosted.com), designed around a dashboard-inspired SaaS visual language.

## Included pages
- `index.html` — Landing page
- `how-it-works.html` — Reservation-to-automation workflow
- `features.html` — New dashboard-inspired feature page
- `pricing.html` — Pricing page
- `sms.html` — SMS Notifications
- `sms-compliance.html` — SMS Compliance
- `signup.html` — Public Get Started / SMS Opt-In form
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Service
- `css/style.css` — Shared styling

## Version 4 feature page
The Features page includes:
- Smart Hosting automation command-center mockup inspired by the supplied dashboard reference
- Airbnb, Vrbo and Booking.com channel cards
- Reservation Sync, Automation Engine, Smart Access, Operational Notifications, Cleaning Coordination and Property Automation sections
- Prototype vs. In-development status labels
- Reservation → workflow → property action visualization
- Roadmap section

## Important
The channel cards use simplified, non-official letter marks rather than reproducing third-party logo artwork. The page includes an independence/trademark notice.

The public signup form from the compliance package remains a front-end demonstration and must be connected to a real consent-recording backend/form provider before being used as a final 10DLC CTA.

Do not place Telnyx API keys, GoDaddy PATs, or other secrets in this website or GitHub repository.
